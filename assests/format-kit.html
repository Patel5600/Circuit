Format kit — inspired by format.obys.agency

Seven partsof one format

Seven interface patterns lifted from the reference site, rebuilt in vanilla HTML, CSS and JS. Each block is self-contained: copy its CSS, its markup and its script.

Scatter canvas

Rotated cards on a dashed-guide canvas. Pointer-capture dragging, z-lift on grab, tilt easing toward flat while held, arrow-key nudging.

Clock dial

Radial 1–12 numerals with free-orbit dots. Drag to move; on release the angle snaps to the nearest hour through a registered @property transition.

(Format)Circle

Tilted type stack

An endless word loop inside a rotated frame. Scroll velocity is fed into the track, decays each frame and skews the type.

Format morph

A single element, four formats. Width, height and radius are CSS custom properties keyed off data-f; the script only flips one attribute.

(Format)Horizontal

Colour reveal

Monochrome art with a lerp-following radial mask that uncovers the colour layer beneath. The imagery is SVG turbulence, so there are no image files.

Move your cursor

Micro-type spec sheet

Spec columns set at 7px scale to readable size on hover or focus while the ghost headline darkens. Dense at rest, legible on demand.
